# Termux Backup Tool v1.2
<img src="https://raw.githubusercontent.com/onxx-x146/Termux-Backup/main/178834.gif" width="200" />
## *🐈‍⬛ Description
Ye ek **powerful Termux Backup & Restore Tool hai jo aapke Termux ke saare important data ko automatically backup karta hai aur Termux uninstall hone ke baad bhi aapka poora data safe aur wapas restore kar deta hai.*

### *🔑 Key Features:*
- ✅ Full Backup — Termux ke saare files ka complete backup
- ✅ Custom Backup — Specific folders select karke backup*
- ✅ Auto Restore Script— Har backup ke saath ek standalone restore script generate hota hai
- ✅ Dual Storage — Backup  dono jagah save hota hai
- ✅ Uninstall-Proof — Termux delete karne ke baad bhi data safe hai
- ✅ Backup History — Saare backups ka list dekho
- ✅ One-Click Restore — Seedha restore karo ya manual tar command use karo
